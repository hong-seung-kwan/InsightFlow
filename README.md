# InsightFlow

Next.js와 Shopify API를 활용한 쇼핑몰 데이터 분석 대시보드입니다.

쇼핑몰의 매출, 주문, 고객 데이터를 한 화면에서 확인할 수 있도록 만들었습니다. 단순히 데이터를 보여주는 것뿐만 아니라 기간별 매출을 비교하고, 주문 상태에 따라 데이터를 조회할 수 있도록 구현했습니다.

Next.js를 처음 사용하면서 App Router 구조를 익히고, React Query를 이용한 데이터 관리와 외부 API 연동을 연습하기 위해 진행한 개인 프로젝트입니다.

## 기술 스택

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **데이터 관리:** TanStack Query (React Query)
- **차트:** Recharts
- **API:** Shopify Admin GraphQL API
- **배포:** Vercel

## 주요 기능

### 1. 대시보드

- 매출, 주문 수 등 주요 지표 확인
- 최근 7일 매출 데이터를 차트로 표시
- 최근 주문 목록 및 주문 상태별 통계
- 주문 상태 카드를 클릭하면 해당 주문 목록으로 이동

### 2. 매출 분석

- 7일, 30일, 90일 기간 선택
- 선택한 기간의 총매출, 평균 매출, 최고 매출 계산
- 이전 기간과 현재 기간의 매출 비교
- Recharts를 이용한 매출 추이 그래프

### 3. 고객 관리

- 고객 수 및 고객 관련 통계 표시
- 고객 목록 테이블 구현

### 4. 주문 관리

- 주문번호 및 고객명 검색
- 주문 상태별 필터링
- 최신 주문순 정렬
- 페이지네이션 구현

### 5. 데이터 모드 전환

데모 데이터와 Shopify API 데이터를 전환해서 확인할 수 있도록 만들었습니다.

- **데모 모드:** 직접 만든 가상 데이터 사용
- **Shopify 모드:** Shopify 개발 스토어의 주문 및 고객 데이터 조회

두 모드에서 동일한 UI를 사용하도록 구성했습니다.

## 구현하면서 신경 쓴 부분

### React Query를 이용한 데이터 관리

처음에는 `useEffect`와 `useState`를 사용해 API 데이터를 가져왔지만, 페이지마다 로딩 상태와 오류 처리를 관리해야 했습니다.

이후 React Query를 적용하여 데이터 조회 로직을 분리하고, `queryKey`를 통해 조회 기간과 데이터 모드에 따라 캐시를 구분했습니다.

또한 `staleTime`을 설정하여 불필요한 재요청을 줄이도록 했습니다.

### Shopify API 연동

Next.js의 Route Handler를 사용하여 Shopify GraphQL API와 통신하도록 구현했습니다.

Shopify 인증에 필요한 Client ID와 Client Secret은 환경변수로 관리하고, 브라우저에서 직접 요청하지 않도록 서버에서 API를 호출하는 구조로 만들었습니다.

API에서 받은 데이터를 화면에 필요한 형태로 변환하여 사용했습니다.

### 반응형 레이아웃

데스크톱뿐만 아니라 모바일에서도 사용할 수 있도록 레이아웃을 수정했습니다.

모바일에서는 사이드바를 버튼으로 열고 닫을 수 있도록 했고, 주문 및 고객 테이블은 화면이 좁아졌을 때 가로 스크롤이 가능하도록 처리했습니다.

## 개발 중 겪었던 문제

### 1. React Query API 요청 반복

개발 중 대시보드 API 요청이 계속 반복되는 문제가 있었습니다.

React Query 설정과 요청 흐름을 확인했고, 개발 서버를 재시작한 후 정상적으로 동작하는 것을 확인했습니다.

### 2. 모바일 화면에서 테이블이 넘치는 문제

주문 목록과 고객 목록을 모바일 화면에서 확인했을 때 테이블이 화면 밖으로 넘어가는 문제가 있었습니다.

테이블을 감싸는 요소에 `overflow-x-auto`를 적용하고 최소 너비를 설정하여 해결했습니다.

### 3. Next.js 빌드 오류

배포 전 `npm run build`를 실행했을 때, 이전에 테스트 목적으로 만들었던 Shopify API Route에서 오류가 발생했습니다.

실제로 사용하지 않는 테스트 API 파일을 제거한 후 다시 빌드하여 정상적으로 완료되는 것을 확인했습니다.

## 프로젝트를 마치며

이번 프로젝트에서는 기존에 사용하던 React와 달리 Next.js의 App Router와 서버 API 기능을 직접 사용해 볼 수 있었습니다.

특히 Shopify API를 연결하면서 외부 API 데이터를 가져와 화면에 맞게 가공하는 과정을 경험할 수 있었습니다.

또한 React Query를 활용한 데이터 관리, 차트 구현, 반응형 레이아웃 수정 등을 통해 프론트엔드 개발에서 고려해야 할 부분들을 연습할 수 있었습니다.
